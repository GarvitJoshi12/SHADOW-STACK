# 🛒 Shadow Stack Grocery Store

## BCA AI & Data Science – 3rd Semester Project

Shadow Stack Grocery Store is a web-based grocery shopping application developed as an academic project for the **BCA (Artificial Intelligence & Data Science) 3rd Semester**.

The project provides an online grocery shopping experience where users can browse products, add products to their cart, manage quantities, enter delivery details, and proceed towards checkout.

## 📌 Project Overview

The main objective of this project is to develop a simple and user-friendly grocery shopping website while understanding the practical implementation of:

- Frontend Web Development
- Backend Development
- Database Connectivity
- REST APIs
- Shopping Cart Management
- Form Validation
- CRUD Operations
